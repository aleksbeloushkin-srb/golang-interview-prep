## 5. Озвучка: как пользоваться

- **Генерация.** Команда для всего, что сейчас озвучено:

  ```
  node scripts/gen-audio.mjs --week 1 --week 2 --week 3 --cards c2,c7,c28,c29,c47,c13,c14,c15,c16,c17,c18,c19,c20,c21,c22,c23,c24,c25,c26,c27,c55,c56 [--dry-run] [--prune]
  ```

  `--dry-run` показывает текст для речи. Генерируются только недостающие файлы — около 30 секунд на файл. Запускать в фоне (`run_in_background`), не через `&`.
- **Устаревшие записи.** Изменил озвученный текст — его запись устарела (`audioStale` в `check-content`). Её нужно пересоздать той же командой.
- **Правила чтения** — `scripts/speech-text.mjs`.
  - Словарь `WORDS`: GOMAXPROCS → «Go max procs», Ps → «P's», IDs → «I-D's» и др.
  - Регулярные правила: `-race` → «dash race», `I/O` → «I-O», «→» → «then», «1 ms» → «one millisecond», `-gcflags=-m`, KiB/MiB, `x := y`, `*T`, `[]T`, `pkg.Name` → «pkg dot Name».
  - Хеш записи считается от экранного текста. Если поменялось только правило чтения, файл нужно удалить вручную и запустить генерацию снова.
- **Точечные правки** — `SPEECH_FIXES` в `scripts/gen-audio.mjs`, по ключу. Если правка перестала совпадать с текстом, генератор падает с ошибкой — значит, её надо обновить.
- **Проверка произношения.** `python3 -c "from kokoro_onnx.tokenizer import Tokenizer; print(Tokenizer().phonemize('текст','en-us'))"`. Заглавные буквы подряд синтезатор читает по буквам; слова в смешанном регистре — словами.
- **Чек-лист прослушивания.** `node scripts/audio-review.mjs` пересобирает `docs/AUDIO_REVIEW_RU.md`: все записи с длительностью, рискованные места наверху (словарь `RISK` в скрипте). Нужен ffprobe.
- **Покрытие на v75:** неделя 1 — 25/25, неделя 2 — 31/31, неделя 3 — 41/41, плюс отдельно c13–c27, c28, c29, c47, c55, c56. Недели 4–13 не озвучены. На слух пользователь записи ещё не принимал.

## 9. Грабли, на которые уже наступали

- `pkill -f serve.py…` в команде, где та же строка встречается ещё раз, убивает собственный шелл (exit 144). Использовать `pkill -f "[s]erve.py 876"`.
- Наборы проверок захардкодили числа: 56 карточек, 12 диаграмм, 47 quiz, 20 строк шпаргалки, число `predict` по диаграммам, карточка «без записи» c3. Обновлять вместе с контентом.
- Под `-race` рантайм не печатает «all goroutines are asleep»: программа просто висит. Учитывать в quiz.
- Ревью других систем часто опираются на старую версию сайта (48 карточек, старые первые фразы). Сначала сверять с текущим `main`.
- Длинная генерация озвучки, запущенная через `&`, умирает с концом ответа. Запускать через `run_in_background`.
- Публикация Pages иногда стоит в очереди GitHub 10–15 минут — это не ошибка.
- github.io из облачной среды закрыт прокси (CONNECT 403). Публикацию проверять через API: `actions/runs` с `head_sha` merge-коммита и `?v=N` в `index.html` на `main`.
