# Фикстура: учебный модуль go-prep

Код со страницы практикума «Свой репозиторий go-prep» (`data/guides.js`, `#/practice/go-prep`): `week1/hello`, `week1/calc` — неделя 1; `week4/asm`, `week4/cmd/sumdemo` — тренировка с ассемблером (неделя 4; до v96 — неделя 3, до v91 — неделя 2); `ci.yml` — файл CI (в репозитории пользователя он лежит в `.github/workflows/`). С v94 в `week1/calc` — образцы справки «Тесты в Go» (`#/practice/go-testing`): `div.go`, `clamp.go` и их тесты, `example_test.go`, `bench_test.go`, `fuzz_test.go`. С v96 в `week3/bitops` — примеры справки «Биты в Go» (`#/practice/go-bits`): `bitops.go` и `example_test.go` с семью Example, вывод которых — строки справки (`docs/verification/v96/check-week3.mjs`). Код разбора 1 недели 3 специально падает на тестах и лежит отдельно — `../review-week3/`. Путь модуля здесь `github.com/you/go-prep`, на странице — `github.com/<ник>/go-prep`; совпадение файлов проверяет `scripts/check-content.test.mjs`.

Проверка: `go vet ./... && go test -race -count=1 ./...` на Go 1.24.7 и последней; выводы тренировки (ассемблер amd64 и arm64, `-m`, `objdump`, `GOSSAFUNC`) сверены 6 ноября 2026 на 1.24.7 и 1.27.3.
