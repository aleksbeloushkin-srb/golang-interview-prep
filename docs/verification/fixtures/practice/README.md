# Практикум недели 3 — эталоны и тесты

Источник кода для раздела `#/practice` (данные — `data/practice.js`; `scripts/check-content.mjs` сверяет их с файлами здесь). В каждом каталоге: эталон `<task>.go`, тесты `<task>_test.go`, заготовка `starter.go.txt`.

```bash
go vet ./... && go test -race -count=1 ./...
```

Проверено Go 1.24.7 (linux/amd64); код совместим с Go 1.25+. Тесты отлавливают типичные ошибки (проверено мутациями: пул без ограничения, воркер без отмены, `close` в каждом отправителе, nil-вход в fan-in, счётчик без блокировки, кеш без копий, нарушенный инвариант).
