# Практикум с errgroup (W4-1) — эталон и тесты

Отдельный модуль, потому что эталон использует `golang.org/x/sync/errgroup`. `go.sum` не хранится: перед запуском выполните `go mod tidy` (нужна сеть).

```bash
go mod tidy && go vet ./... && go test -race -count=1 ./...
```

Проверено Go 1.24.7 с `golang.org/x/sync` v0.18.0 (последний выпуск, совместимый с Go 1.24; выпуски с v0.20 требуют Go 1.25+, v0.24 — Go 1.26). Без сети проверка шла через временный `-modfile` с `replace` на локальную копию x/sync той же версии.
