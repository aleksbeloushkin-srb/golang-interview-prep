## 3. Что изменилось в общих местах (важно для твоих порций)

- `js/app.js`: в шаблон схемы добавлены `#<sim>-board` и `<details id="<sim>-table">`; `boardHtml` рисует схему из `step.board`. Если у шага есть `board`, таблица шага уходит внутрь свёрнутого `details`; без `board` всё как раньше. Кнопки шагов: номер плюс название (до 640 px скрыто, полное — в `aria-label`); стрелки влево/вправо на списке шагов. `renderSimStep(i, k)` по-прежнему главный вход. `CARD_TO_SIM`: c21 → sim8.
- Формат `board`: массив панелей `{ caption?, lanes?: [{ kind, title, tag?, state?, slots: [{ label, items, queue? }], note? }], hl?: [id], hlLabel?, hlQuiet?, list?: { title?, items, ordered? } }`. Панель может быть только списком. Элемент — `"G1"` или `{ g, flag?, hl? }`; `hl: true` выделяет один элемент, `hl` панели — все элементы с таким `g`. `hlLabel` меняет слово «изменилось», `hlQuiet` оставляет только рамку (для читалки — «выделено»). `kind`: p, grq, netpoll, timer, sysmon, syscall, m, g, dir, table, group, var, chan, white, grey, black, other. Легенда — `sim.boardLegend`.
- Поле шага `predict: { promptEN, promptRU }` (только вместе с `board`): описание и схема прячутся в «Показать ответ». Сейчас predict на 17 шагах.
- sim3 больше не использует `scene`; рендер `scene` и стили `.channel-*` в коде остались (не мешают; можно удалить при случае).
- `scripts/check-content.mjs`: проверка плана, `validateBoard`, `liquidHazards` по всем отслеживаемым `.md`. Ресурсы `?v=34`.
