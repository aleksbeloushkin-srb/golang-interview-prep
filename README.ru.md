Сайт для подготовки к собеседованиям на Go-бэкенд: рантайм, конкурентность, идиомы, устройство сервиса и задачи с тестами. Чистые HTML, CSS и JavaScript, без сборки и внешних зависимостей.

**Сайт:** https://aleksbeloushkin-srb.github.io/golang-interview-prep/

Интерфейс на русском. Ответы — на английском, чтобы проговаривать их вслух, и рядом с каждым есть объяснение по-русски.

### План

- Недели 1–4 — язык и конкурентность, 5–8 — учебный проект (ledger-сервис), 9–13 — форматы собеседований: take-home и код-ревью, system design, behavioral, пробные интервью.
- Календарь начинается с твоей даты (понедельник недели 1) и сдвигается на неделю; подсвечен сегодняшний день и что в нём осталось.
- Задачи отмечаются галочкой, у недели — счётчик. У многих задач есть «Готово, когда», у LeetCode — подсказка, которую открывают после своей попытки, у части — эталонный ответ на английском. Отметки плана можно скачать и загрузить в JSON.
- Тренажёр проговора: Clarify → Approach → Complexity → Edge cases, таймер на шаг, эталон, самооценка и слабые шаги.

### Карточки

- 28 карточек Base, 35 Senior и 9 Deep Dive. Фильтры: модуль, уровень, поиск, «На повторение», «С практикой».
- Сначала вспомнить: сказать вслух первую фразу и ответить своими словами; застрял — открыть опоры (`H`); потом сверить и оценить себя: «Не ответил», «С опорой» или «Сам ✓».
- Оценка задаёт дату следующей проверки: завтра, через 2 дня или, если «Сам ✓» подряд, через 4, 8, 16 и затем 30 дней. «Продолжить занятие» берёт до 10 карточек: сначала просроченные, потом непроверенные карточки текущей недели плана.
- В карточке: короткий ответ на английском, «Если спросят про Java и Kotlin» (у 70 карточек), как это работает — на английском с переводом, где это пригодится, код, версии и источники, упражнение, ссылки на диаграмму и задачи quiz.
- Клавиши: `H` опоры, `Пробел` ответ, `←`/`→` листать, `L` слушать, `1` сам, `2` с опорой, `3` не ответил.

### Диаграммы

Стек и регистры, планировщик GMP, каналы, `select`, CAS, аллокатор и GC, мапы, `sync.Mutex`, битовые операции, HTTP-запрос в `net/http`, deadlock и livelock, дерево «канал или мьютекс». Шаг — доска с дорожками и фишками: изменённые фишки помечены Δ, ниже — список «Что изменилось», в конце — вопрос для самопроверки. На 35 шагах сначала нужно предсказать результат. У шага своя ссылка (`#/simulators/sim9/3`), у диаграммы — список её карточек.

### Quiz

Фрагмент кода, от четырёх до шести вариантов, объяснение по-русски, ответ для проговора по-английски, исправленный код у 40 задач и ссылки на карточки. Режим «Сначала свой ответ» прячет варианты, пока не запишешь свой.

### Практикум

- 26 задач недель 1–6 и 9: деньги и ошибки, `defer`, generics, CSV-утилита, worker pool, pipeline, fan-in и fan-out, errgroup, token bucket, graceful shutdown, утечка горутин, escape analysis, pprof, HTTP API, обёртка с таймаутом, параллельные переводы, идемпотентность, outbox, tee и or-done.
- В задаче: контракт на английском и русском, заготовка, тесты для `go test -race`, подсказки по одной, эталон, объяснение на английском за минуту, частые ошибки и вариации; у 15 задач — ещё «3 проверки перед отправкой».
- «Проверить на сервере» прогоняет вставленное решение теми же тестами с `-race` на Go 1.27.3, без доступа в сеть; нужен вход.
- Эталоны и тесты лежат в `docs/verification/fixtures/practice/`; тесты проверены заведомо сломанными решениями.
- **Свой репозиторий go-prep** (`#/practice/go-prep`): один модуль, по пакету на задачу, тренировка run, build, vet и test, CI на GitHub Actions, вывод компилятора и ассемблер (`-S`, `-m`, `GOSSAFUNC`, objdump), справка команд и где живёт Go: `GOROOT`, `GOPATH` и кэши.
- **Трек «Каналы и context»** (`#/practice/track-channels`): 28 кат в 5 блоках — от основ каналов через `select`, `context` и утечки к fan-in, fan-out, pipeline, ограничению параллелизма, errgroup и rate limiting; есть разбор чужого кода и таблица отличий версий Go. Те же каты стоят в днях плана недель 4–12; ката пройдена, когда отмечена её задача плана.

### База знаний

Все 72 темы карточек на одной странице и два эталонных проекта с порядком чтения кода:

- [go-payments-reference](https://github.com/aleksbeloushkin-srb/go-payments-reference) — платёжный сервис: идемпотентное создание платежа, очередь задач на PostgreSQL (`SKIP LOCKED` и аренда), outbox, вебхуки, long polling, graceful shutdown и фейковый шлюз со сбоями.
- [pinkponies-bank](https://github.com/aleksbeloushkin-srb/pinkponies-bank) — три сервиса: ledger на gRPC с двойной записью и холдами, переводы как оркестрируемая сага с outbox в Kafka и идемпотентный консьюмер Kafka с dead-letter topic.

### Озвучка

148 записей на английском (Kokoro TTS, голоса Michael и более медленный Heart): короткие ответы и сравнения с Java у 52 карточек, эталонные ответы недель 1–3 плана и объяснения 12 задач практикума. Кнопка «Слушать» появляется, только если запись сделана для текущего текста.

## Вход и прогресс

- «Войти через Google» — через Amazon Cognito (authorization code с PKCE); токены хранятся только в памяти. Оценки карточек, отметки и дата старта плана, результаты тренажёра и решённые задачи синхронизируются с сервером, поэтому прогресс одинаков на всех устройствах. Если устройства разошлись, их можно объединить или оставить одну сторону.
- Без входа сайт только для чтения: материалы, quiz и заготовки доступны, отметки не сохраняются.
- Пока войти могут только тестовые аккаунты: приложение Google OAuth в режиме тестирования.
- Бэкенд: [golang-interview-prep-api](https://github.com/aleksbeloushkin-srb/golang-interview-prep-api) — Go-функции AWS Lambda, Cognito, прогресс с оптимистичной блокировкой и раннер `go test -race` без доступа в сеть.

## Версии Go

Текущей сайт считает Go 1.27.3. Примеры и тесты практикума проверяются на Go 1.24.7 и 1.27.3. Где версии различаются, в материале сказано, что изменилось и когда: `sync.WaitGroup.Go` появился в 1.25, профиль утечек горутин в 1.26 был экспериментом, а в 1.27 включён по умолчанию. У каждой карточки и задачи quiz есть заметка о версиях и источники.

## Локальный запуск

```bash
git clone https://github.com/aleksbeloushkin-srb/golang-interview-prep.git
cd golang-interview-prep
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8000`, остановить — Ctrl+C. `js/config.js` указывает на публичный бэкенд, поэтому такая копия только для чтения. Чтобы прогресс хранился в браузере, запусти без бэкенда: `python3 docs/verification/browser/serve.py 8765 --root . --no-backend`.

## Проверки

| Команда | Что проверяет |
|---|---|
| `node scripts/check-content.mjs --base <commit>` | синтаксис и структуру данных, ID, ссылки, код практикума против фикстур, свежесть озвучки, Liquid в отслеживаемых `.md` |
| `node --test` | `scripts/*.test.mjs`: сам проверяющий скрипт, реестр источников Go, слияние прогресса, расписание повторения |
| `go vet ./... && go test -race -count=1 ./...` | эталоны практикума, запуск в `docs/verification/fixtures/practice` |
| `docs/verification/browser/check-*.js` | наборы Playwright, см. [их README](docs/verification/browser/README.md) |

Проверку Go-содержания они не заменяют. Порядок проверки — [VERIFICATION_WORKFLOW_RU.md](VERIFICATION_WORKFLOW_RU.md), правила для участников и агентов — [AGENTS.md](AGENTS.md).

```text
index.html         каркас страницы и навигация
```
