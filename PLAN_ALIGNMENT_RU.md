**4. Практикум недель 3–4**

| Задача | Пакет/упражнение | Что проверяет тест |
|---|---|---|
| W3-1 | workerpool | Ограничение параллелизма; закрытие results после всех воркеров; отмена; медленный потребитель |
| W3-2 | pipeline | Остановка всех стадий при отмене или уходе потребителя |
| W3-3 | fanin | Закрытие выхода после закрытия всех входов; отмена; пустой набор входов |
| W3-4 | counter | Mutex, atomic и канал дают один результат под `-race`; бенчмарк без выводов «всегда быстрее» |
| W3-5 | safecache | Составной инвариант под RWMutex; ссылка на защищённые данные не уходит наружу |
| W4-1 | parallelfetch | Первая ошибка отменяет остальные; SetLimit; все запущенные операции завершены к возврату |
| W4-2 | ratelimit | Отказ сверх лимита; burst; восстановление; сравнение с x/time/rate |
| W4-3 | shutdown | Прекратить приём → дождаться работы в полёте → закрыть зависимости; таймаут |
| W4-4 | leak | Утечка и исправление; тест завершения своих горутин, не `NumGoroutine` |
| W4-5 | escape | Объяснение вывода `-gcflags=-m`, изменение, перепроверка |
| W4-6 | profile | Наблюдение → гипотеза → изменение → повторный бенчмарк |

`-race` не доказывает отсутствие deadlock и логических ошибок, поэтому у каждого задания есть тесты контракта.
