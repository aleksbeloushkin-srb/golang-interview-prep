## 3. Что изменилось в общих местах (важно для твоих порций)

- `js/app.js`: в шаблон схемы добавлены `#<sim>-board` и `<details id="<sim>-table">`; `boardHtml` рисует схему из `step.board`. Если у шага есть `board`, таблица шага переносится внутрь свёрнутого `details`; без `board` всё как раньше. Кнопки шагов: номер плюс название (до 640 px скрыто, полное — в `aria-label`); стрелки влево/вправо на списке шагов. `renderSimStep(i, k)` по-прежнему главный вход.
- Формат `board` (необязательный): массив панелей `{ caption?, lanes: [{ kind, title, tag?, state?, slots: [{ label, items, queue? }], note? }], hl?: [id], list?: { title?, items, ordered? } }`; элемент — `"G1"` или `{ g: "G1", flag: "…" }`. `kind`: p, grq, netpoll, timer, sysmon, syscall, m, g.
- `scripts/check-content.mjs`: проверка `data/plan.js` (если файл есть; удалённый ID задачи с `--base` — ошибка), `validateBoard`, `liquidHazards` — двойные фигурные скобки или фигурная скобка с процентом вне блока raw в любом отслеживаемом `.md` дают ошибку. Это защищает сборку Pages. В счётчиках появились `planWeeks/planTasks/planAcceptance`.
- Ресурсы `?v=26`. Поле шага `predict` (необязательное, только вместе с `board`): описание шага переносится внутрь свёрнутого блока «Показать ответ» и возвращается на место при переходе к другому шагу.
