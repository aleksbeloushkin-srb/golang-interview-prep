# Браузерные проверки Claude (Playwright)

Наборы, которыми Claude проверял сайт перед каждым PR (v60–v75). Раньше они жили только в рабочей папке сессии; здесь — чтобы новая сессия могла их запускать.

## Запуск

Нужен Node и Playwright с Chromium: `require('playwright')` и `chromium.launch()` без опций. В облачной среде Claude они уже установлены.

Из корня репозитория поднять два локальных сервера:

```bash
python3 docs/verification/browser/serve.py 8765 --root . --no-backend &   # без бэкенда: всё редактируется локально
python3 docs/verification/browser/serve.py 8767 --root . &                # с js/config.js: режим «только чтение» без входа
node docs/verification/browser/check-nav.js                              # каждый набор печатает PASS/FAIL и «N/M passed»
```

Остановить серверы: `pkill -f "[s]erve.py 876"`. Не пишите слово `serve.py` в той же команде: шаблон pkill совпадёт с собственной командной строкой и убьёт её.
