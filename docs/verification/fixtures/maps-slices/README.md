# Проверки порции 11: slices/maps

Изолированный Go-модуль для проверки учебных примеров; сайт остаётся статическим, сборки не требует.

Из этого каталога:

```sh
go test -count=1 -v ./...
go vet ./...
go run ./c29
go run ./c30
go run ./c32
go run ./q6
go run ./q6-fixed
```

Ожидаемый вывод:

| Пример | Вывод |
|---|---|
| c29 | `[9 2] [7 2 3] [9 8]` |
| c30 | `1`, затем `2` |
| c32 | `0 1`, затем `0 0` |
| q6 | `4 4` |
| q6-fixed | `3 4` |

`main.go` совпадают с кодом карточек/quiz. `semantics_test.go` проверяет перенос на варианты: ограничение cap и индексная запись, shallow copy указателей, alias/замена/clear, nil map, NaN, удаление непосещённых записей при range. Порядок range, точный cap после роста, RSS и длительность GC не фиксируются. Примеры однопоточные; race-проверка не требуется для заявленных свойств.

Фактический прогон: Go 1.26.1 darwin/arm64. `go 1.21` — минимальная версия синтаксиса модуля из-за clear, а не заявление о запуске на 1.21. Старые версии сверены по tagged source; Go 1.17/1.25 здесь не запускались.

Целевой браузерный сценарий: из корня репозитория запустить HTTP-сервер и временный Chrome по VERIFICATION_WORKFLOW_RU.md, затем:

```sh
node docs/verification/fixtures/maps-slices-browser.mjs --output /tmp/maps-target.json
```

Node с fetch/WebSocket (проверен 22.10.0), CDP по умолчанию на 9228. Скрипт использует отдельный временный browser context. Скриншоты пишутся в `/private/tmp/maps-*.png`; их нужно просмотреть отдельно. После проверки остановить HTTP-сервер и Chrome. Исходники runtime сверяются вручную по ссылкам и SHA256 в отчёте `docs/verification/2026-10-27-maps-slices.json`: поведенческие тесты не доказывают внутреннее устройство map.
