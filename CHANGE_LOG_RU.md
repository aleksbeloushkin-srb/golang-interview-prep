**Формат обязательной записи после каждого этапа реализации**

| Поле | Что записывать |
|---|---|
| Дата и статус | Выполнено / частично / отложено; не смешивать с планом |
| Проблема | Конкретный пользовательский сценарий или ошибочное утверждение |
| Было | Наблюдаемое поведение или прежний EN/RU ответ |
| Стало | Новое поведение и точная новая формулировка |
| Почему | Техническая причина и польза для подготовки/запоминания |
| Как | Существенные изменения данных, функций, UI и миграции |
| Где | Файлы и стабильные ID карточек, quiz, схем и шпаргалки |
| Источники | Спецификация/API/исходник с версией; отдельно учебные исследования |
| Совместимость | Старые ссылки, ID, storage, история повторений, EN/RU |
| Проверка | Какие команды и сценарии реально выполнены, их результат |
| Ограничения | Что не проверено, какие допущения остаются |

Для крупных изменений дополнительно давать связное подробное объяснение решения, включая выбранную альтернативу и основания выбора. Не ограничиваться перечислением изменённых файлов. Если меняется Go-факт, фиксировать все связанные места и оба языка; если меняется оценка знаний, описывать влияние на старый прогресс. Для переезда — порядок переноса данных и отката. Для ИИ — набор проверочных ответов и ограничения автоматической оценки.

**Следующая запись** появится после фактической реализации первого согласованного этапа. Пункты плана не являются выполненной работой.
