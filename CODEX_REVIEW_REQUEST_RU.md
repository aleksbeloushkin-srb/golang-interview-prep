1. c39: не стало ли описание `errors.Is` слишком размытым; верно ли «первая ошибка» для `As` в обходе дерева.

3. U5: порог 30 % и поведение на реальном крупном шрифте (не только CSS 200 %); нет ли скачков панели при открытии ответа.
4. R3: достаточно ли `Decode` + `io.EOF`; не стоило ли вынести общий помощник для трёх handler-ов.
